# Gerenciador de Produtividade

Programa em Python que pergunta quantas tarefas foram realizadas, registra o tempo gasto em cada uma e calcula o total de minutos.

## O que o programa faz

1. Pede o nome da pessoa.
2. Pergunta quantas tarefas foram realizadas.
3. Usa um laço `for` para receber o tempo de cada tarefa.
4. Soma os minutos usando uma variável acumuladora.
5. Usa uma função com `return` para classificar o tempo total.

## Conceitos praticados

- Variáveis e `input()`
- Conversão com `int()`
- Laço `for` e `range()`
- Operações matemáticas e acumuladores
- Funções, parâmetros e `return`
- Condicionais `if`, `elif` e `else`

## Como executar

Execute o arquivo `gerenciador_produtividade.py` em um ambiente com Python 3 instalado.
